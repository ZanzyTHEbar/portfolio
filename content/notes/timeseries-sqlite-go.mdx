Memory servers and metrics endpoints both hold timestamped data. A dedicated time-series cluster adds operational weight that conflicts with the single-binary thesis behind MCP Memory.

SQLite in Go could act as a time-series engine in one file and one binary, following the same instinct as a libSQL-backed memory server. Careful indexing may support workloads SQLite was not marketed for.

It remains unverified which ingest and recall shapes this can support.
