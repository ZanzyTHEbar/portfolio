Reliable event delivery is a deployment requirement for an agent. DragonScale also needs durable side effects across crashes and restarts without heavyweight infrastructure.

A transactional outbox writes an event to SQL in the same transaction as the state change, then relays it through NATS. An outbox table and relay fit the small-runtime thesis.

It remains open whether the relay should use at-least-once delivery with idempotent consumers or exactly-once delivery, and where the outbox table belongs when the runtime uses libSQL.
