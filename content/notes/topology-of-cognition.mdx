If agents need an intermediate representation and persistent memory, both rest on the same unsettled question: what shape does machine reasoning actually have? That is the problem this note circles, with AIRE's ambition on one side and MCP Memory on the other.

Working-note speculation: latent-space geometry — directions, neighborhoods, composition — might supply that shape, constraining both what an agent IR can express and what a memory store should index. Vector-plus-hybrid search and knowledge graphs are then two probes at the same unknown, not two separate features.

No claims here beyond the anchor: representations first, runtimes second. Everything else stays an open question until the reading and the building meet, and the date and URL behind this piece are verified.
