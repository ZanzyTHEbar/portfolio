AIRE's agent IR and MCP Memory's persistent memory both raise representation questions. This is a speculative working note.

Latent-space directions, neighborhoods, and composition frame questions about what an agent IR expresses and a memory store indexes. Vector-plus-hybrid search and knowledge graphs are ways to examine that relationship.
