Agents may need both an intermediate representation and persistent memory. Both depend on the unsettled question of machine reasoning's shape. AIRE approaches it through an agent IR, and MCP Memory approaches it through persistent memory.

Latent-space geometry, including directions, neighborhoods, and composition, might constrain what an agent IR can express and what a memory store should index. Vector-plus-hybrid search and knowledge graphs can probe the same question.

The representation-first idea remains an open question until reading and building meet.
