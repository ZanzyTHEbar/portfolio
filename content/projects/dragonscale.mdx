## Strange Idea

A Go binary can combine a narrow agent runtime with explicit trust boundaries.

## Hypothesis

In ZanzyTHEbar/dragonscale, the Isolated Tool Runtime routes tool calls through SecureBus.

## Constraints

- Tools declare capabilities to SecureBus.
- SecureBus injects secrets and scans tool output.
- The main runtime executes in process.

## System

ZanzyTHEbar/dragonscale is a fork of sipeed/picoclaw. It is a compact Go single-binary runtime for Linux and embedded environments with persistent memory and DAG execution. Its Isolated Tool Runtime routes tool calls through SecureBus for capability checks, secret injection, and LLM-facing output scanning. The main runtime executes in process, and the documented Isolated Tool Runtime does not enforce network or filesystem boundaries.
