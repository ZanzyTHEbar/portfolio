## Strange Idea

Can an AI agent runtime be small enough to actually deploy?

## Hypothesis

If capabilities are minimized and the trust boundary is explicit, then agents can run on constrained infrastructure.

## Constraints

- memory
- security
- latency
- tool isolation
- local deployment

## System

Agents stay undelivered while runtimes are heavy and trust boundaries are vague. DragonScale answers with a compact Go single binary: a capability bus (SecureBus), persistent memory, DAG execution, and MCP tool isolation.

## Reality

Open-source runtime under active development.

## Open Questions

- Benchmarks and evaluations are unmeasured on this page; performance claims await a reproducible harness.
- How does SecureBus compare to MCP-native isolation?
- Where the outbox table lives when the runtime itself is backed by libSQL.
