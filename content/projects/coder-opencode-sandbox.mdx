## System

coder-opencode-sandbox provisions one OpenCode workspace per user on Coder through Authentik OIDC. The workspace provides the OpenCode web UI, terminal access, and a persistent volume for configuration, database, and shell history. A Terraform template, GHCR-built sandbox image, and Coolify post-deploy registration support the deployment.
