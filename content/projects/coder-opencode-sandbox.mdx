## System

Cloud dev environments usually mean shared boxes, password auth, and state that vanishes on stop. This provisions per-user OpenCode sandboxes on Coder behind Authentik OIDC — one workspace per user with the OpenCode web UI, terminal access, and a persistent volume carrying config, database, and shell history — with a Terraform template, GHCR-built sandbox image, and Coolify post-deploy registration.
