## System

A Mealie instance holds recipes, shopping lists, and meal plans behind a REST API built for clicks. mealie-mcp exposes that whole API surface as MCP tools over StreamableHTTP — generated from the Mealie OpenAPI spec, with token auth, configurable base URL, and extras like TDEE-based nutrition planning — so cooking infrastructure becomes callable from Claude, Cursor, and other MCP clients.
