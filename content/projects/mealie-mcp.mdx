## System

mealie-mcp exposes Mealie's recipes, shopping lists, and meal plans as StreamableHTTP MCP tools. It is generated from the Mealie OpenAPI specification and supports token authentication, a configurable base URL, and TDEE-based nutrition planning. MCP clients such as Claude and Cursor can call the resulting tools.
