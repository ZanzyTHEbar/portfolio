## Strange Idea

Persistent agent memory runs from a single Go binary backed by libSQL.

## Hypothesis

MCP Memory supports vector, text, and hybrid search.

## Constraints

- zero runtime deps
- multi-project isolation

## System

MCP Memory is a single Go binary on libSQL with vector and hybrid search, knowledge graphs, and multi-project isolation. It includes database benchmarks for vector, text, and hybrid search.
