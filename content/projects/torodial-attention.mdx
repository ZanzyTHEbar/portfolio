## System

Linear attention geometries can penalize the far end of long contexts by construction. Toroidal attention models the context window as a 3D toroidal structure. It uses circular wrapping like HDD tracks and depth stacking like platters with sparse cross-depth fusion. It also has blockwise computation for long contexts and an FFT approximation path. The project is self-marked highly experimental. Its repository evaluation claims require test-suite validation.
