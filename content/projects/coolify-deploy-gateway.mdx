## System

Coolify Deploy Gateway is a stdlib-only Go HTTP ingress for private Coolify deployments. A single route accepts GitHub push webhooks, verifies the HMAC signature against a per-target secret, checks the repository and ref allowlist, and forwards validated events to the Coolify deploy API. Payloads are capped at 1 MiB, duplicate deliveries are dropped by a short-lived body-fingerprint cache, and the Coolify client only dials private origins with a deploy-scoped token. Docker ships a distroless image with a healthcheck endpoint.
