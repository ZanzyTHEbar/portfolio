## System

latex2go is a Go CLI that parses LaTeX math expressions and emits Go code. Package and function names are configurable, with output to stdout or files.

- [ZanzyTHEbar/latex2go](https://github.com/ZanzyTHEbar/latex2go): LaTeX-to-Go transpiler.
