## System

Equations live in papers while implementations get retyped by hand, errors included. latex2go is a Go CLI that parses LaTeX math expressions and emits the equivalent Go code, with configurable package and function names and stdout-or-file output. Self-declared personal work-in-progress and passion project; a transpiler experiment kept at honest scope.
