## System

Prompts grown by concatenation rot: no structure, no reuse, formatting quirks leaking into logic. poml-go is a pure-Go implementation of Microsoft's Prompt Orchestration Markup Language — HTML-like semantic components, a CSS-like styling system decoupled from content, a templating engine with variables and loops, plus a Go SDK and CLI — so agent prompts become maintainable artifacts instead of fragile strings.
