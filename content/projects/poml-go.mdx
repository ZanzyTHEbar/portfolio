## System

Prompts assembled through string concatenation can lack structure and reuse, and formatting can leak into logic. poml-go is a pure-Go implementation of Microsoft's Prompt Orchestration Markup Language. It provides HTML-like semantic components, a CSS-like styling system separate from content, a templating engine with variables and loops, and a Go SDK and CLI. The design separates agent-prompt content from styling.
