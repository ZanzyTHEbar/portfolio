## System

Dragonarchy is a personal-host Arch/Hyprland reference configuration. Ansible manages system state, and chezmoi manages user dotfiles. Manifests record ownership, while age and sops manage secrets. A guarded path retains the deprecated stow-and-scripts flow. Its scope excludes distribution.
