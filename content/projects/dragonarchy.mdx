## System

Workstations drift: packages, dotfiles, and secrets diverge until reinstalls become archaeology. Dragonarchy is an opinionated Arch/Hyprland setup run as a declarative control plane — Ansible for system state, chezmoi for user dotfiles, manifests for ownership, age/sops for secrets — with the legacy stow-and-scripts flow deprecated behind a guard. Personal-host scoped by its own admission; a reference, not a distro.
