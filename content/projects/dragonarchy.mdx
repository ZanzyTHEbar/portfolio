## System

Packages, dotfiles, and secrets can diverge across a workstation. Dragonarchy is an opinionated Arch/Hyprland setup. Ansible manages system state, chezmoi manages user dotfiles, manifests record ownership, and age/sops manages secrets. The legacy stow-and-scripts flow is deprecated behind a guard. The project is scoped to a personal host and serves as a reference configuration, not a distribution.
