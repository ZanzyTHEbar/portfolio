## Strange Idea

What if VR eye tracking ran on commodity ESP32 boards?

## Hypothesis

If firmware handles camera streaming, networking, and OTA robustly, then hobbyist boards can carry real eye-tracking workloads.

## Constraints

- embedded RAM
- Wi-Fi bandwidth
- multi-board variants
- power

## System

Real eye-tracking workloads should not need exotic hardware. This work is firmware plus Python tooling for commodity ESP32 boards — camera streaming, Wi-Fi, USB (UVC/CDC), health checks, board configs — with automated multi-board releases via CI.

## Reality

Shipped inside the EyeTrackVR ecosystem with releases and OTA.
