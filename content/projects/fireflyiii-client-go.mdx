## System

Firefly III users who write Go otherwise hand-roll the same HTTP against its API. This is a comprehensive Go client for the Firefly III API — built against its OpenAPI 3.0 spec, with personal-access-token auth, pagination, context support, and structured error handling — so self-hosted finance data is one idiomatic import away.
