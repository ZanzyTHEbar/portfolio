## System

Exposing one MCP server is a demo; operating many for many tenants is infrastructure. MCP Edge Gateway is a Go runtime for a shared MCP edge and control plane — authenticated public HTTP entrypoints, subject-aware tenant routing, SQLite/libSQL persistence with migrations, full OAuth surfaces, and a control plane that reconciles tenant services, shipping with Docker Compose and Coolify deployment templates.
