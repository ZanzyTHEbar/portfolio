## System

MCP Edge Gateway is a Go runtime for a shared MCP edge and control plane. It exposes authenticated HTTP endpoints, routes requests by subject, and persists services and migrations in SQLite/libSQL. OAuth surfaces, a service-reconciliation loop, and Docker Compose and Coolify deployment templates are included.
