## Strange Idea

A one-meter, printable, bucket-based garden tower has a basic-build target under $20.

## Hypothesis

For a 20-liter bucket tower, modular 3D-printable parts, ESP32 control, and browser flashing define build cost, setup steps, and automated garden control.

## Constraints

- Basic-build cost target under $20
- Access for non-coders through browser flashing, without an IDE
- Light, water, nutrients, and airflow

## System

ESP32GreenhouseTowerDIY is an open-source modular tower garden with interlocking 3D-printable segments on a 20-liter bucket adapter. An optional aeroponics variant uses a high-pressure nozzle. An ESP32 controls lighting, pumps, fans, and sensors. The design uses WebSerial for browser flashing and MQTT for Home Assistant reporting. Power and sensing use a custom PCB with off-the-shelf fallbacks. Arduino Core is the main codebase; MicroPython remains as a legacy implementation. MQTT discovery uses mDNS to locate a broker on the local network.

## Decisions

- Firmware moved from MicroPython to Arduino Core for more sensors, faster loops, and lower power.
- Browser-based flashing was selected to support non-coders.
