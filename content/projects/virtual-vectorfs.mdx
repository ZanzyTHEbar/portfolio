## System

Hierarchical paths locate files. Agents may also need queries by meaning, similarity, and proximity. virtual-vectorfs is a pre-alpha virtual filesystem in Go on embedded libSQL. It supports concurrent operations over hierarchical organization, vector search for semantic similarity, full-text search, spatial indexing, and git integration. The project is moving quickly. Its current bet puts storage, search, and meaning in one binary.
