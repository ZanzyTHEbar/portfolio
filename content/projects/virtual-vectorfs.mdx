## System

Hierarchical paths answer one question — where — while agents need what, what-like, and what-nearby. virtual-vectorfs is a virtual filesystem in Go on embedded libSQL: concurrent operations over hierarchical organization, with vector search for semantic similarity, full-text search, spatial indexing, and git integration. Pre-alpha and moving fast; the bet is that storage, search, and meaning belong in one binary.
