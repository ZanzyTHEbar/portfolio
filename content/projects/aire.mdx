## System

AIRE is a private clean-room v1 TypeScript library for Bun. Its runtime executes a versioned intermediate representation through adapters. A process adapter ships, and v1 workflow compilation is sequential-only.

## Reality

The package remains private while build, publishing, and Node-compatibility boundaries are finalized.

## Open Questions

- IR workflow shapes beyond sequential steps.
- Adapters after process execution and the public API boundary.
