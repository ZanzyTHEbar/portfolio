## System

Agents need something between a prompt and a process: an execution intermediate representation. AIRE is a harness-agnostic tool-execution runtime — an adapter-first design where natural-language plans compile to an IR and execute deterministically through adapters (a process adapter ships; a compiler seam for richer workflows is in progress). The current checkout is a clean-room v1 in TypeScript on Bun; the package stays private until the API settles.

## Reality

Active clean-room rewrite; the documented behavior above describes the v1 scaffold, not a finished release.

## Open Questions

- What the compiler seam grows into — which workflow shapes the IR can express beyond sequential steps.
- Which adapters come after process execution, and what the public API freeze looks like.
