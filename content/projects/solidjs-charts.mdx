## Strange Idea

Chart.js components can use SolidJS reactivity.

## Hypothesis

Explicit Chart.js registration maps selected controllers, elements, scales, and plugins to tree-shakable imports in SolidJS components.

## Constraints

- bundle size and tree shaking
- required Chart.js registration for controllers, elements, scales, and plugins
- Solid reactivity semantics without virtual-DOM assumptions

## System

solid-chartjs wraps Chart.js for SolidJS. It provides chart-type components over explicitly registered Chart.js controllers, elements, scales, and plugins. Its tree-shakable import path includes the controllers and scales selected by an application. ZanzyTHEbar/solid-chartjs is a fork of s0ftik3/solid-chartjs.

## Evidence

- [ZanzyTHEbar/solid-chartjs](https://github.com/ZanzyTHEbar/solid-chartjs): SolidJS component for Chart.js.
