## Strange Idea

Chart.js components can use SolidJS reactivity.

## Hypothesis

Explicit Chart.js registration maps selected controllers, elements, scales, and plugins to tree-shakable imports in SolidJS components.

## Constraints

- bundle size and tree shaking
- required Chart.js registration for controllers, elements, scales, and plugins
- Solid reactivity semantics without virtual-DOM assumptions

## System

solid-chartjs wraps Chart.js for SolidJS. It provides chart-type components over explicitly registered Chart.js controllers, elements, scales, and plugins. Its tree-shakable import path includes the controllers and scales selected by an application.

## Reality

The package is published to npm with a demo site and usage documentation. ZanzyTHEbar/solid-chartjs is a fork last pushed on 18 January 2025. Its differences from upstream are unknown.

## Open Questions

- The fork's fixes, upstream tracking, and role as a personal mirror need clarification.
