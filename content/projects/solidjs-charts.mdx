## Strange Idea

Chart.js bindings can follow SolidJS reactivity.

## Hypothesis

Fine-grained bindings may update dashboards without full-chart rerenders or extra framework code.

## Constraints

- bundle size and tree shaking
- required Chart.js registration for controllers, elements, scales, and plugins
- Solid reactivity semantics without virtual-DOM assumptions

## System

solid-chartjs wraps Chart.js for SolidJS. It provides chart-type components over explicitly registered Chart.js pieces. Its tree-shakable import path lets applications bundle only the controllers and scales they use.

## Reality

The package is published to npm with versioned releases, a demo site, and usage docs. The repository under the author's account is a maintained fork. Its differences from upstream are unstated here.
